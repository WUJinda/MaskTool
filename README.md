# mask-tool

本地文件脱敏工具（CLI），用于在将文件提交给AI或外部系统前进行敏感信息脱敏，并支持后续还原（可逆脱敏）。

## 特性

- **可逆脱敏**：敏感信息替换为唯一Token（如 `[COMPANY_001]`），支持反脱敏还原
- **不可逆脱敏**：替换为 `***`
- **格式支持**：Word(.docx)、Excel(.xlsx)，支持文件名/目录名脱敏
- **智能识别**：正则规则 + 词典匹配，按置信度分级处理
- **批次化输出**：每次运行产物写入独立批次目录，映射表带批次标识与指纹
- **本地运行**：所有处理本地执行，禁止调用外部API

## 能力边界

| 格式 | 状态 | 说明 |
|------|------|------|
| Word (.docx) | ✅ 支持 | 正文/表格/嵌套表格/页眉页脚（含首页/奇偶页变体）/脚注/尾注/批注/文本框/超链接；文档属性（作者等元数据）自动清空 |
| Excel (.xlsx) | ✅ 支持 | 单元格/富文本/数字（货币格式、Luhn 卡号）/公式字面量/批注/页眉脚/数据验证列表/定义名称 |
| 文件名/目录名 | ✅ 支持 | 目录模式下对输出镜像树自底向上改名，映射表 `paths` 段记录，可还原 |
| PowerPoint (.pptx) | ⛔ 已屏蔽 | 跨 run 替换可靠性未达标准，暂不开放（代码保留，命中即警告跳过） |
| PDF (.pdf) | ⛔ 已屏蔽 | 无回写能力，暂不开放（代码保留，命中即警告跳过） |

## 快速开始

```bash
# 安装
pip install -e .

# 生成默认配置与示例词库（内嵌模板，任意目录可用）
mask-tool config

# 启动 Web 界面（可视化检测/勾选/脱敏/还原）
mask-tool-web
```

### Web 界面与临时自定义敏感词

除 CLI 外，`mask-tool-web`（或 `streamlit run src/mask_tool/web/app.py`）提供可视化流程：上传 docx/xlsx → 检测表格 → 勾选确认 → 脱敏下载，并可用 mapping.json 反向还原。

检测页提供两个针对"自动检测误报多、只想针对性脱敏"场景的控件：

- **临时自定义敏感词**（文本框）：每行一个词或用逗号分隔，手动指定本次任务关注的敏感信息。手动词按词库语义精确匹配（置信度 0.95，自动脱敏档），生成 `[CUSTOM_xxx]` Token，与自动检测结果合并展示并置顶、标"✍️ 手动"来源；仅本次任务生效，不写入词库文件，重新检测后保留。自动检测误报的词（如普通词被识为人名），可加入 `config/whitelist.yaml` 的 whitelist 永久排除。
- **仅脱敏我指定的词**（开关，默认关）：开启后完全跳过自动检测（NER/正则/词库均不运行），检测表格与脱敏只处理手动指定的词——适合只关注特定敏感信息、不想处理自动检测其余命中的场景。

两控件留空/关闭时不改变任何既有流程行为。中途可随时点侧边栏顶部"🔄 新建任务"（或检测页"⬅️ 重新上传文件"、完成页"🆕 开始新任务"）放弃当前流程重新开始：已上传文件、检测结果、勾选与产物全部清空，运行设置与临时自定义敏感词保留。

**目录批量脱敏（zip 形式）**：把整个目录压缩成 zip 在上传区旁的"或上传目录压缩包（.zip）"入口上传，工具递归处理其中的 docx/xlsx（沿用侧边栏设置与自定义敏感词），pptx/pdf 等屏蔽类型警告列出且不进产物；脱敏产物为同结构目录的 zip 下载，mapping.json 另有单独下载按钮。恢复还原页对称支持：上传脱敏 zip + mapping.json，还原为同结构 zip。

**下载规则**：上传单文件 → 直接下载脱敏后的同名单文件；多文件或目录 zip → 下载同结构 zip 压缩包。⚠️ mapping.json 是还原钥匙（含原文↔占位符对照）：请与脱敏文件分开保管，勿一起外发。
# 脱敏处理（单文件：产物主名同步脱敏并追加 _masked 后缀，
# 如 合同-某某公司.docx -> 合同-[COMPANY_001]_masked.docx；
# --no-mask-names 关闭主名脱敏，产物为 {原名}_masked.ext）
mask-tool mask input.docx --mode smart --output ./output/

# 脱敏处理（目录：递归处理 docx/xlsx，非文档原样拷贝，
# 空目录一并迁移；默认对文件名/目录名脱敏（处置集与内容一致：
# 默认仅自动脱敏项，--all 时含建议项），--no-mask-names 关闭）
mask-tool mask ./项目资料/ --output ./output/

# 查看检测结果（不执行脱敏；提取与脱敏同源，表格/页眉脚/脚注无盲区）
mask-tool inspect ./项目资料/

# 反脱敏（还原原文；目录输入时内容与文件名/目录名一并还原）
mask-tool unmask "<批次目录>/<脱敏后目录>" --mapping "<批次目录>/mapping.json" --output ./restored
```

## 批次目录与还原

每次 `mask` 运行创建独立批次目录 `output/<时间戳-短uuid>/`，内含：

- 脱敏产物（单文件为脱敏主名 + `_masked` 后缀；目录模式为镜像树，保持原文件名）
- `mapping.json`：token -> 原文映射 + `paths` 段（文件名/目录名改名记录）+ `metadata`（batch_id / 生成时间 / 工具版本 / 源文件清单 / 指纹）
- `report.json`：脱敏报告

目录模式 + `--confirm` 下，未勾选任何项（内容未脱敏）的文件不会混入镜像树，
而是拷入镜像树内 `skipped_unmasked/` 隔离子目录（保持原名、不做名字脱敏），
摘要会提示数量；请勿把该目录内文件当作脱敏产物分发。

`mask` 结束时会打印还原命令示例。还原时建议整批使用同一份 `mapping.json`；跨批次混用或映射表被手工改动可通过 `--verify`（指纹复算比对）发现；unmask 启动时还会将实际输入文件与映射表登记的源文件清单比对，完全无交集时给出警告提示（不阻断）。

unmask 防线（M3）：

- **还原后对账扫描**：输出全文若残留映射表内的 token（还原缺陷）将报错退出，`--force` 可忽略；残留不在映射表内的 token 样式文本（文档自然内容或跨批次文件）仅警告，不做还原。
- **编号让位**：mask 前预扫描文档中已存在的 token 样式串（如 `[PERSON_001]`），新生成编号自动跳过，防止撞号导致误还原。

## 处置分级与 --all / --confirm（行为变化）

按置信度分级：**自动脱敏**（smart 模式 ≥0.85）、**建议脱敏**（≥0.6）、**仅提示**。

> **v0.2 行为变化（H6）**：默认 mask 仅替换"自动脱敏"项；"建议脱敏"项不再默认替换（旧版会被替换）。文件名/目录名脱敏的处置集与内容一致（默认仅自动脱敏项）。需要一并替换时：

```bash
# 建议脱敏项也替换
mask-tool mask input.docx --all

# 交互式逐项勾选（检测结果全量展示，含表格/页眉脚等全部件；
# 未勾选项即使达到自动脱敏阈值也不替换）
mask-tool mask input.docx --confirm
```

## 运行模式

| 模式 | 说明 |
|------|------|
| `focused` | 仅词库精确匹配（0.95）自动脱敏 |
| `strict` | 仅高置信度自动脱敏（0.95），次高建议 |
| `smart`（默认） | 词库 + 正则 + NER，标准阈值（0.85/0.6） |
| `aggressive` | 高召回优先，降低阈值 |

## 脱敏对象

支持以下类别的敏感信息：
- 公司名称（我方/对方/关联方）
- 政府机构
- 人名
- 地名
- 项目名称
- 标的物名称
- 金额（`amount_mode`: `token` 可逆 / `fuzzy` 模糊化如 1.2亿 → 1亿+ / `fixed` 即 `***`）
- 自定义关键词
- 手机号 / 身份证号 / 银行卡号 / 邮箱 / 日期（正则）

## 配置

编辑 `config/default.yaml` 自定义配置，或通过命令行参数覆盖。配置加载回退链：显式 `--config`（缺失即报错）→ 当前目录 `config/default.yaml` → 内嵌模板 → 纯代码默认；每次回退均警告并打印生效的词库路径。`lexicon.yaml` 缺失时会自动从同目录 `sample_lexicon.yaml` 复制创建。

## 已知限制

- **docx 修订记录**：未接受的修订（`w:ins`/`w:del`）不处理——修订删除的文本（`w:delText`）不参与检测替换，修订人姓名等元数据也不会清除。交付前请先接受所有修订。
- **段内混合格式退化**：docx 中替换发生过的段落，整段文本并入首个 run（保留其格式），该段其余 run 的局部格式（加粗/颜色等）不再生效。
- **跨 tab/换行实体**：docx 中 `w:tab`/`w:br` 是结构元素而非文本；跨制表符/软换行的实体字符可被检测替换与还原，但重建后 tab/换行可能偏离原位置（位置漂移），重要文档请人工复核。
- **roundtrip 前提**：unmask 仅保证对未再编辑的脱敏文档完整还原；xlsx 批注作者（author）单向清除，不在还原范围。
- **xlsx 大整数精度**：≥16 位的整值数字（含 openpyxl 读入为 float 的形态）在未脱敏保留时统一预转为文本存储（逐位保真）；16–19 位 Luhn 校验通过的卡号等 `kind=number` 整值 token 还原为数值（int），超过 19 位的还原为文本。
- **Web 检测临时副本**：Web 端检测后直接关闭页面时，上传副本可能残留在系统 temp 目录；建议完成脱敏流程或再次点击"重新检测"触发清理。
- **xlsx 线程批注**：openpyxl 不支持线程批注（threadedComments），保存时该部件会被丢弃，运行时有告警提示。
- **路径超长**：改名后绝对路径超过 Windows MAX_PATH 限制时保留原名（不截断 token）并警告。
