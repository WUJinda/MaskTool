## 1. 产品概述

### 1.1 工具简介

mask-tool 是一款**本地运行的文件脱敏工具**：把 Word / Excel / 文本型 PDF 中的公司名、人名、手机号、证件号、金额等敏感信息，替换为占位符（`[COMPANY_001]`）或自然伪装词（`汤姆`、`A集团`），用于把文件安全地交给 AI 或外部系统处理；需要时凭映射表（`mapping.json`）**一键还原原文**。

### 1.2 核心能力

| 能力 | 说明 |
| --- | --- |
| 可逆脱敏 | 敏感信息替换为唯一替换串，凭 `mapping.json` 无损还原；还原后自动对账扫描，残留即报错 |
| 两种替换风格 | **占位符（token，默认）**：`[COMPANY_001]`，一眼可见已脱敏；**伪装词（alias）**：人名→汤姆、地名→A市、公司→A集团，文档观感像普通文件，还原逻辑完全一致 |
| 智能识别 | 词库精确匹配 + 正则（手机号 / 身份证 / 银行卡 / 邮箱 / 日期）+ NER（可选）+ 手动指定词，按置信度分级处置 |
| 深度格式覆盖 | docx 正文 / 表格 / 嵌套表格 / 页眉页脚 / 脚注尾注 / 批注 / 文本框；xlsx 单元格 / 富文本 / 公式字面量 / 批注 / 数据验证列表；PDF 原位擦除替换 |
| 文件名也脱敏 | 目录模式下输出镜像树的文件名 / 目录名同步脱敏，可一并还原 |
| 批次化管理 | 每次运行产物写入独立批次目录，映射表带批次标识与指纹，防跨批次混用 |

### 1.3 安全模型

- **本地优先**：全程在本机运行，仅监听 `127.0.0.1`，关闭遥测；默认配置下**没有任何外部 API 调用**，数据不出本机。
- **可选项**：AI 增强检测（第 4.8 节）默认关闭；启用后会把待判定文本片段发送到你在设置弹窗里配置的端点（通常为内网模型服务）。是否启用由你决定。
- **映射表是钥匙**：`mapping.json` 明文存有"替换串 ↔ 原文"对照，必须与脱敏产物分开保管，绝不外发（详见第 11 节）。

## 2. 安装与启动

### 2.1 方式一：免安装便携版（Windows 普通用户推荐）

1. 从 Releases 页下载 `mask-tool-portable-v*.zip`（约 135 MB）；
2. 解压到任意目录（免管理员权限，不写注册表，卸载即删目录）；
3. 双击 `mask-tool.exe`。依赖全部内置；仅需系统 WebView2 运行时（Win10 较新版本 / Win11 随 Edge 自带）。

个人词库与配置保存在 exe 同级 `config\` 目录，随目录一起迁移；升级覆盖软件目录前请先备份词库。

### 2.2 方式二：Python 安装（开发者 / macOS）

```bash
pip install -e .            # 基础（CLI）
pip install -e ".[app]"     # 桌面应用完整依赖（UI 内核 + 原生窗口）
mask-tool config            # 生成默认配置与示例词库
```

要求 Python ≥ 3.9。

### 2.3 启动方式

| 入口 | 命令 / 操作 | 适合场景 |
| --- | --- | --- |
| 桌面窗口 | 双击 `start-windows.bat` / `start-mac.command`，或 `mask-tool app` | 日常使用：原生窗口、原生保存对话框、无需命令行 |
| 命令行 | `mask-tool mask / unmask / inspect / config` | 脚本化、批量任务 |

桌面窗口关闭即完全退出，不残留后台服务。旧版独立浏览器入口（`mask-tool-web`）已下线，界面在桌面窗口内渲染。

## 3. 快速上手：五分钟走通全流程

以桌面窗口为例（命令行等效操作见第 12 节附录）：

**第 1 步 · 上传**：启动软件，在「📤 上传」页拖入或选择 1 个 / 多个 docx、xlsx、xlsm、pdf 文件；整个目录可压成 zip 上传（第 4.7 节）。

**第 2 步 · 检测**：点「🔍 开始检测」。工具列出识别到的敏感项表格（类别、来源、置信度、默认处置）。

**第 3 步 · 确认**：表格中勾选要脱敏的项（默认已勾选"自动脱敏"级），可在检测前用文本框临时补充自定义敏感词（第 4.5 节）。

**第 4 步 · 执行脱敏**：点「💾 执行脱敏」。完成后按提示把脱敏产物保存到目标文件夹；`mapping.json`（还原钥匙）单独保存、单独保管。

**第 5 步 ·（需要时）还原**：切到「恢复还原」页，选择历史批次或手动上传 `mapping.json`，再上传脱敏文件 / zip → 一键还原原文。还原完成后自动对账，若产物中仍有替换串残留会红字提示（第 5.4 节）。

## 4. 功能详解

### 4.1 敏感信息识别

| 识别来源 | 覆盖内容 | 说明 |
| --- | --- | --- |
| 词库（dictionary） | 公司 / 机构 / 政府 / 人名 / 项目 / 标的 / 自定义关键词 | 精确匹配，置信度 0.95，`config/lexicon.yaml` 维护 |
| 正则（regex） | 手机号 / 身份证 / 银行卡 / 邮箱 / 日期 / 金额 | 内置规则 |
| NER（可选） | 人名 / 地名 / 机构名 | jieba 智能识别，`config/default.yaml` 的 `ner.enabled` 开启 |
| 手动指定（manual） | 任意词 | 检测页文本框临时输入，仅本次任务生效（第 4.5 节） |
| AI 增强（可选，默认关） | 复核 / 增量识别边界模糊的候选 | 内网 OpenAI 兼容端点（第 4.8 节） |

**处置分级**（smart 模式默认阈值；可在配置文件调整）：

| 级别 | 置信度 | 默认行为 |
| --- | --- | --- |
| 自动脱敏 | ≥ 0.85 | 直接替换 |
| 建议脱敏 | ≥ 0.6 | 表格中列出，确认勾选或 `--all` 后替换 |
| 仅提示 | < 0.6 | 列出不替换 |

**运行模式**（侧栏「运行模式」或 `--mode`）：

| 模式 | 说明 |
| --- | --- |
| focused | 仅词库精确匹配自动脱敏，最快最稳 |
| strict | 仅高置信度（0.95）自动脱敏 |
| **smart（默认）** | 词库 + 正则 + NER，标准阈值 |
| aggressive | 高召回优先，降低阈值 |

### 4.2 替换风格：占位符（token）与伪装词（alias）

两种风格产物形态对比（同一输入"李海富就职于某某科技有限公司，常驻北京市海淀区，电话 13800138000，年薪 120 万元"）：

| 风格 | 产物示例 | 特点 |
| --- | --- | --- |
| token（默认） | `[PERSON_001]就职于[COMPANY_001]，常驻[LOCATION_001]，电话[CUSTOM_001]，年薪[AMOUNT_001]` | 一眼可见已脱敏；适合内部流程 / AI 处理后再还原 |
| alias | `汤姆就职于A集团，常驻A市，电话[CUSTOM_001]，年薪[AMOUNT_001]` | 实体类换成自然词，文档观感像普通文件；金额 / 手机号等数字类仍为占位符 |

**alias 风格的类别边界**（数字类伪装无意义且风险高，恒为占位符）：

| 类别 | 伪装词示例（内置词池） |
| --- | --- |
| 人名 | 汤姆、杰瑞、张三、李四…（内置 48 个，顺序取用） |
| 地名 | A市、B市…Z市、A省、B省…（字母 × 市/省/县/区） |
| 公司 | A集团、B集团…A公司、B公司…（字母 × 集团/公司/企业/厂） |
| 机构 / 政府 | A单位、B单位…A局、B委…（字母 × 单位/局/委/部/厅/办） |
| 项目 / 标的 | A项目、B工程…（字母 × 项目/工程/标的/课题） |
| 词库与手动自定义词 | 甲、乙、丙…（天干地支 22 个） |
| **金额、手机号、身份证、银行卡、邮箱、日期** | **保持占位符**（`[AMOUNT_001]` 等） |

alias 风格要点：

- **同一实体同一伪装词**：同批次内（跨文件）"李海富"恒为"汤姆"；
- **自动避让**：工具预扫描全部文档文本，原文中已存在的词不会被用作伪装词（防还原撞词）；含 XML 拆分、实体转义等存储形态均已处理；
- **词池可自定义**：编辑 `config/alias_lexicon.yaml`（第 7.3 节）；文件删除则回退内置默认池；
- **词池耗尽不中断**：某类别词池用完时自动回退该类占位符样式，收尾时 CLI 打黄色警告 / 窗口弹提示（如"伪装词池已耗尽（PERSON），部分实体回退占位符样式"），扩充词池即可避免；
- **风格选择入口**：CLI `--style token|alias`；桌面窗口侧栏「脱敏选项 → 替换风格」下拉框（选择会记住）。**不显式选择时读配置文件 `mask_style`（默认 token）**；
- **限制**：alias 批次的 `mapping.json` 标记 `metadata.style = "alias"`，旧版本工具无法还原 alias 批次；实体边界由词表决定（检出"北京"会留下后缀，请把完整地名如"北京市"维护进词库）。

### 4.3 文件名与目录名脱敏

目录（树）模式下，输出镜像树的文件名 / 目录名同步脱敏并记录到映射表 `paths` 段，还原时一并改回。CLI 用 `--no-mask-names` 关闭（关闭后单文件产物主名仍会加 `_masked` 后缀）。alias 风格下文件名同样生效：`李海富13800138000合同.docx` → `汤姆[CUSTOM_001]合同.docx`（人名得伪装词、手机号保持占位符）。

### 4.4 金额脱敏模式

配置 `amount_mode`（或配置文件）三选一：

| 模式 | 产物 | 说明 |
| --- | --- | --- |
| token（默认） | `[AMOUNT_001]` | 可逆 |
| fuzzy | `1.2亿元 → 1亿+` | 模糊化，不可逆 |
| fixed | `***` | 完全遮蔽，不可逆 |

### 4.5 手动自定义敏感词与"仅脱敏我指定的词"

检测页提供两个控件（命令行 `--confirm` 模式的等效补充）：

1. **临时自定义敏感词**：每行一个词或逗号分隔（如 `某某科技有限公司，张三丰，2026年Q3财报`）。按词库语义精确匹配、置信度 0.95 自动脱敏档，表格置顶并标「✍️ 手动」；仅本次任务生效，不写入词库文件；
2. **仅脱敏我指定的词**开关（默认关）：开启后完全跳过自动检测（NER / 正则 / 词库均不运行），只处理手动指定的词——适合自动检测误报较多的场景。

自动检测的误报词可加入 `config/whitelist.yaml` 永久排除。

### 4.6 不可逆脱敏

侧栏「不可逆脱敏」开关或 CLI `--irreversible`：敏感信息替换为 `***`，**不再可还原**（映射表不生成对应还原信息）。确定不需要还原时使用。

### 4.7 目录批量（zip）处理

桌面窗口：把目录压成 zip，在「或上传目录压缩包（.zip）」入口上传。工具递归处理其中 docx / xlsx / xlsm / pdf（自定义敏感词、仅手动模式照常生效；pptx 警告且不进产物），完成后下载同结构目录 zip。恢复还原页对称支持 zip 还原。CLI 目录模式（`mask-tool mask <目录>`）等效且同时做文件名脱敏。

### 4.8 AI 增强检测（可选，默认关闭）

设置弹窗「模型配置」可接入 **OpenAI 兼容端点**（Ollama / vLLM / Xinference / One-API 类网关，通常为内网服务），两种角色：`adjudicator`（复核边界候选）/ `detector`（AI 增量识别）/ `both`。

- 默认关闭；开启前需在设置中完成端点连通测试；
- 模型配置（含 API Key）保存在本机 `config/app_settings.yaml`（该文件不入 Git）；
- **注意**：启用后待判定文本片段会发送到所配置的端点。若端点为外部互联网服务，工具会要求你确认信任该端点后才生效；坚持本地优先时保持关闭即可，核心功能完全不依赖它；
- 仅增强 smart / aggressive 模式；单次运行有调用数预算上限（默认 200 次），超出自动跳过。

## 5. 还原：把脱敏文件变回原文

### 5.1 还原钥匙：mapping.json

每次脱敏生成的 `mapping.json` 包含：

| 段 | 内容 |
| --- | --- |
| `tokens` | 替换串 → 原文、类别、置信度等（如 `"汤姆": {"original": "李海富", ...}`） |
| `metadata` | 批次号、时间、工具版本、输入文件清单、运行模式、**替换风格（style: token / alias）** |
| `paths` | 文件名 / 目录名改名记录（目录模式） |

**保管要求**：与脱敏产物分开存放；不随脱敏文件外发；跨批次不可混用（第 5.4 节防线可发现混用）。

### 5.2 桌面窗口还原

「恢复还原」页 → 选择「从历史记录恢复」（自动带出该批次映射表）或「手动上传文件恢复」（上传 `mapping.json`）→ 上传脱敏文件 / 脱敏 zip → 还原 → 保存还原产物。还原完成自动对账（第 5.4 节）。

### 5.3 命令行还原

```bash
mask-tool unmask "<批次目录>/source" --mapping "<批次目录>/mapping.json" --output ./restored
```

目录输入时内容与文件名一并还原；`--force` 忽略对账报错（不建议），`--verify` 复算映射表指纹（发现手工改动 / 跨批次混用）。

### 5.4 还原防线（自动执行）

| 防线 | 作用 |
| --- | --- |
| 还原后对账扫描 | 输出全文若残留映射表内的替换串（token 正则 + alias 逐词精确查）= 还原缺陷，CLI 报错退出 / 窗口红字列出具体文件与残留词；残留不在映射表内的占位符样式文本仅警告不处理 |
| 编号让位 | 脱敏前预扫描文档中已存在的占位符串（如原文自带 `[PERSON_001]`），新生成编号自动跳过，防撞号误还原 |
| 源文件对账 | unmask 启动时比对实际输入与映射表登记的源文件清单，完全无交集时警告 |
| 指纹校验（`--verify`） | 复算映射表指纹，发现映射表被手工改动或跨批次文件混入 |

### 5.5 还原前提

- unmask 保证对**未再编辑的脱敏文档**完整还原。脱敏后又编辑过的文档（增删文本）可能破坏替换串，还原结果不保证逐字一致；
- alias 批次还原后，对账保证映射表内伪装词零残留；

## 6. 批次与产物管理

每次 `mask` 运行创建独立批次目录 `output/<时间戳-短uuid>/`：

```text
output/20261016-093404-ddf00d/
├── <脱敏产物>            # 单文件：xxx_masked.docx；目录模式：source/ 镜像树
├── mapping.json          # 还原钥匙（单独保管！）
├── report.json           # 处理报告（检测项 / 处置 / 耗时统计）
└── skipped_unmasked/     # 确认模式下未勾选文件的隔离区（内含未脱敏原件，勿外发！）
```

- 批次目录不覆盖历史，定期清理即可；
- `mask` 结束时 CLI 会打印本批次的还原命令示例；
- 桌面窗口「恢复还原 → 从历史记录恢复」按批次列出历史映射表。

## 7. 配置参考

### 7.1 配置文件与加载回退链

主配置 `config/default.yaml`。加载优先级：显式 `--config`（缺失即报错）→ 当前目录 `config/default.yaml` → 内嵌模板 → 纯代码默认；每次回退均警告并打印生效的词库路径。`mask-tool config` 命令可重新生成默认配置与示例词库。

### 7.2 default.yaml 字段速查

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `mode` | smart | 运行模式：focused / strict / smart / aggressive |
| `thresholds.auto_mask` | 0.85 | 自动脱敏阈值 |
| `thresholds.suggest_mask` | 0.6 | 建议脱敏阈值 |
| `ner.enabled` | false | NER 智能识别开关（引擎 jieba） |
| `llm.*` | 关闭 | AI 增强检测（端点 / 模型 / 角色 / 预算等，见第 4.8 节；API Key 优先读环境变量 `MASKTOOL_LLM_API_KEY`） |
| `amount_mode` | token | 金额脱敏：token / fuzzy / fixed |
| `mask_style` | token | **替换风格：token / alias**。优先级：CLI `--style` / 窗口显式选择 > 本配置 |
| `alias_lexicon_path` | config/alias_lexicon.yaml | 伪装词池文件（缺失用内置默认池） |
| `lexicon_path` | config/lexicon.yaml | 自定义词库（缺失时自动从 sample_lexicon.yaml 复制创建） |
| `whitelist_path` | config/whitelist.yaml | 白名单（误报排除） |
| `storage.mapping_format` | json | 映射表格式 json / sqlite |
| `performance.max_file_mb` | 500 | 单文件大小上限 |
| `categories` | （有序列表） | 脱敏类别优先级 |

### 7.3 alias_lexicon.yaml（伪装词池）

```yaml
person:              # 人名池：顺序取用；池内词彼此不应互为前缀
  - 汤姆
  - 杰瑞
location_suffixes:   # 地名：字母 × 后缀展开（A市 B市 … Z市 A省 …）
  - 市
  - 省
company_suffixes:    # 公司：A集团 B集团 … A公司 …
  - 集团
  - 公司
government_suffixes: # 机构/政府：A单位 B局 …
  - 单位
  - 局
project_suffixes:    # 项目/标的：A项目 B工程 …（project 与 subject 共用）
  - 项目
  - 工程
custom_pool:         # 词库与手动自定义词：天干地支
  - 甲
  - 乙
```

自定义建议：人名池按顺序取用，放多少词就能支持多少个不同人名；后缀模板每类最多 26 × 后缀数个词。**避免使用单字或超常见词**（降低脱敏后再编辑文档时的还原误伤）；生成时自动避让原文已有词、过滤 Windows 文件名非法字符；池耗尽回退占位符并警告。

## 8. 词库管理

| 文件 | 职责 | 维护方式 |
| --- | --- | --- |
| `config/lexicon.yaml` | 自定义敏感词库（公司 / 人名 / 项目等，最常用） | 文本编辑，或桌面窗口侧栏「词库管理」增删与批量导入（YAML / TXT）；确认模式下勾选的词默认自动学习进来（`--no-learn` 或窗口开关可关） |

## 9. 支持格式与能力边界

| 格式 | 状态 | 说明 |
| --- | --- | --- |
| Word (.docx) | ✅ 完整支持 | 正文 / 表格 / 嵌套表格 / 页眉页脚 / 脚注尾注 / 批注 / 文本框；文档属性（作者等元数据）自动清空 |
| Excel (.xlsx / .xlsm) | ✅ 完整支持 | 单元格 / 富文本 / 数字（货币格式、Luhn 卡号）/ 公式字面量 / 批注 / 页眉脚 / 数据验证列表 / 定义名称；xlsm 宏部件原样保留（**宏源码不参与脱敏**，需人工确认） |
| PDF (.pdf) | ✅ 文本型支持 | PyMuPDF 原位擦除 + 插入占位符；扫描件 / 加密件明确报错；还原排版为近似恢复（字号自适应），重要文档请人工校对；图片内文字 / 批注 / 表单域不在脱敏范围；还原产物会去除原 PDF 的加密 / 权限标志 |
| 文件名 / 目录名 | ✅ 支持 | 目录模式镜像树自底向上改名，可还原 |
| PowerPoint (.pptx) | ⛔ 屏蔽 | 跨 run 替换可靠性未达标准，命中即警告跳过；请先转 docx 或手工脱敏 |

**已知限制（重要文档交付前请阅读）**：

- **docx 修订记录**：未接受的修订不处理，修订删除的文本不参与检测，修订人姓名等元数据不清除。交付前先在 Word 里"接受所有修订"；
- **段内混合格式退化**：docx 中发生过替换的段落，整段并入首个 run（保留其格式），该段其余 run 的局部格式（加粗 / 颜色等）不再生效；
- **跨 tab / 换行实体**：可检测替换与还原，但重建后 tab / 换行位置可能漂移；
- **xlsx 大整数**：≥16 位整值数字未脱敏保留时统一预转文本存储（逐位保真）；16–19 位 Luhn 卡号还原为数值，超 19 位还原为文本；
- **xlsx 线程批注**：保存时该部件会被丢弃（运行时有告警）；批注作者单向清除不在还原范围；
- **路径超长**：改名后绝对路径超过 Windows MAX_PATH 时保留原名并警告；
- **检测临时副本**：检测后直接关窗，上传副本可能残留在系统 temp 目录；完成流程或点「重新检测」可触发清理。

## 10. 常见问题（FAQ）

**Q1：控制台 / 命令行输出中文乱码？**
Windows 先执行 `set PYTHONIOENCODING=utf-8` 再运行命令。

**Q2：自动检测把普通词当人名 / 公司名（误报多）？**
① 把误报词加入 `config/whitelist.yaml` 永久排除；② 或改用 focused 模式（仅词库匹配）；③ 或用"仅脱敏我指定的词"开关完全跳过自动检测。

**Q3：某个敏感词没被检测到（漏检）？**
把它加入 `config/lexicon.yaml`（词库精确匹配最可靠）；地名请写完整（"北京市"而非"北京"）。

**Q4：出现"伪装词池已耗尽"警告？**
该类别实体数超过词池容量，超出部分已回退占位符样式（还原不受影响）。按第 7.3 节扩充对应词池即可。

**Q5：还原时报错"残留映射表内替换串"（CLI）或还原完成页红字提示？**
产物中检测到映射表内登记的替换串 = 还原缺陷，或映射表与本批文件不对应（跨批次混用）。请核对映射表与文件的批次一致性；`--force` 可忽略但不建议；确认无误后仍报错请保留现场反馈问题。

**Q6：还原后内容和原件不完全一致？**
核对是否满足还原前提（第 5.5 节）：脱敏文档未被再编辑、映射表为本批次原表。docx 段内格式退化、PDF 排版近似恢复属已知限制（第 9 节）。

**Q7：旧版本工具能还原 alias 批次吗？**
不能。alias 批次 `mapping.json` 的 `metadata.style = "alias"`，需 v0.1.0 及以上版本还原；新版本还原旧 token 批次完全兼容。

**Q8：PPT / 扫描件 PDF 怎么处理？**
pptx 整体屏蔽（警告跳过）；扫描件（图片式）PDF 明确报错不支持——请先转 docx / OCR 后再脱敏。

**Q9：多个批次能共用一个 mapping.json 吗？**
不能。每批次独立映射表；混用会被源文件对账警告，`--verify` 指纹校验可发现。

**Q10：`config/app_settings.yaml` 里存的 API Key 安全吗？**
保存在本机该文件中（明文、不入 Git）。请自行确保机器与目录访问权限；也可改用环境变量 `MASKTOOL_LLM_API_KEY`。

## 11. 安全与交付注意事项

1. **mapping.json 是钥匙**：明文含"替换串 ↔ 原文"对照。与脱敏产物分开存放、分开传输，绝不随脱敏文件外发；
2. **`skipped_unmasked/` 是隔离区**：确认模式下未勾选的文件（未脱敏原件）在其中，勿作为脱敏产物分发；
3. **交付前自查**：抽检产物中敏感信息是否全部替换；文件名 / 目录名是否也已脱敏；
4. **docx 修订**：先"接受所有修订"再脱敏；
5. **alias 风格交付**：伪装词使文档"看起来正常"，交付前务必确认替换已覆盖全部敏感项（看检测报告 `report.json` 的处置统计）；
6. **AI 增强检测**：默认关闭；启用即表示你知悉待判定文本将发送至所配置端点，内网端点不受影响；
7. **本地优先**：除你显式配置的 AI 增强检测外，本工具无任何外部网络调用。

## 12. 附录：CLI 命令速查

```bash
# 检测预览（不执行脱敏）
mask-tool inspect <文件或目录>

# 脱敏（smart 模式；产物写入 ./output/<批次>/）
mask-tool mask input.docx --mode smart --output ./output/

# 伪装词风格（不传 --style 时读配置文件 mask_style，默认 token）
mask-tool mask input.docx --style alias --output ./output/

# 目录递归（文件名同步脱敏；--no-mask-names 关闭）
mask-tool mask ./项目资料/ --output ./output/

# 建议脱敏项也替换 / 交互式逐项勾选（勾选词默认学习进词库）
mask-tool mask input.docx --all
mask-tool mask input.docx --confirm            # --no-learn 关闭学习

# 不可逆脱敏（***，无法还原）
mask-tool mask input.docx --irreversible

# 指定配置文件
mask-tool mask input.docx --config path/to/default.yaml

# 还原（目录输入时内容与文件名一并还原；--verify 复算指纹）
mask-tool unmask "<批次目录>/source" \
  --mapping "<批次目录>/mapping.json" --output ./restored --verify

# 生成默认配置与示例词库 / 版本信息
mask-tool config
mask-tool version

# 启动桌面应用窗口
mask-tool app
```
